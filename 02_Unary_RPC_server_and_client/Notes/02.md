With grpc service definition in proto, we now need a new command to generate the client/server stubs as well; `protoc -I=./02_Unary_RPC_server_and_client/proto --go_out=./02_Unary_RPC_server_and_client/proto_gen/users/ --go-grpc_out=./02_Unary_RPC_server_and_client/proto_gen/users --go_opt=paths=source_relative --go-grpc_opt=paths=source_relative ./02_Unary_RPC_server_and_client/proto/users.proto`

An implementation snippet for client and server is done in cmd/main.go. there we implmenent the server and client with some comments to guide.

So

- Client and server stubs both live in \*\_grpc.pb.go
- Types and schemas are defined in \*.pb.go
